# LEAKAGE_POLICY — 컨닝 vs 정당한 과거 이득 (형·커서 합의 SSOT)

📅 개정: 2026-07-30 · ROK21 테스트로또 · 배제번호·백테스트 공통

---

## 1. 한 줄

| 구분 | 허용 |
|------|------|
| **컨닝 (금지)** | 백테 **1120회**를 평가할 때 **1120 이후(1121~1234)** 정보 사용 |
| **정당한 이득 (허용)** | **1235회** 예측할 때 **1~1234회**까지 당첨번호·패턴 사용 |

「미래 회차를 **미리 본 것처럼** 백테에 넣으면」 컨닝.  
「이미 추첨된 과거를 **1235 예측 재료**로 쓰는 것」은 컨닝 **아님**.

---

## 2. 용어 (한글)

| 용어 | 뜻 |
|------|-----|
| **as_of(회차 T)** | T회 **직전까지** draw만 DB에서 읽음 (`draw_no < T`) |
| **walk-forward (WF)** | 매 회차 as_of 적용 · `_get_draws_before` · `set_learn_as_of` |
| **미래 누수** | T 예측·백테에 `draw_no >= T` 데이터가 섞임 |
| **과거 이득** | T 예측에 `draw_no < T` 전부 사용 (1234까지 알면 1235에 사용 OK) |

---

## 3. 시나리오표

| 상황 | 1120 백테 | 1235 실전 예측 |
|------|-----------|----------------|
| 1~1119 당첨번호 | ✅ 사용 | ✅ 사용 |
| 1120 당첨번호 | ❌ **백테 1120 평가 전 사용 금지** | ✅ (1120 추첨 후) |
| 1121~1234 당첨 | ❌ **1120 백테에 절대 금지** | ✅ (각 회차 추첨 후) |
| 1235 당첨 | ❌ | ❌ (추첨 전) |
| 배제 catalog 전체(1~1234) | ❌ 1120 백테에 **통째** 적용 금지 | ✅ 1235용 **as_of(1235)** |

---

## 4. 배제번호 레이어 — 누수 방지 규칙

1. **catalog 빌드:** 회차 T마다 **`build_exclude_catalog(as_of=T)`** — T 미만 draw만.
2. **백테:** 1120 pool/배제 = **1119까지** 통계만 · 1234까지 한 번에 만든 표 **금지**.
3. **실전 1235:** 1234까지 catalog → UI 「1235 예측용 배제」표시.
4. **갱신:** 1235 추첨 **후**에만 1235 당첨을 catalog에 반영 (다음 1236용).
5. **검증:** survey마다 `no_peek: true` · per-draw `as_of` 로그 · PIN 체크리스트.

---

## 5. PIN (패치·백테 전 확인)

- [ ] `set_learn_as_of(draw_no)` 매 WF 회차 호출
- [ ] `_get_draws_before(target)` only
- [ ] 배제·힌트·pool 캐시 키에 **`as_of_draw`** 포함
- [ ] 백테 JSON에 `draw_range` · `as_of_policy: walk_forward`
- [ ] UI: 미추첨 회차는 「추첨 전」·false tier 없음
