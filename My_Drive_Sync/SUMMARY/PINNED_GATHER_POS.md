## 승인 시 자동 진행 규칙

1. 형 **「핀 GO」** 1줄 → NEXT=`K-POS-TRACE` 고정 → 커서 **즉시 ① 실행**
2. ① PASS → 문서동기 후 **자동으로 ②** (추가 승인 불필요 · READ-ONLY 구간)
3. ② PASS → **자동 ③**
4. ③ PASS → **자동 ④**
5. ④ 결과 보고 후 **⑤만** 형 GO 재요청 (배선·세트수 변경)

READ-ONLY ①~④는 연속 진행. 멈춤은 실패·형 중단·⑤ 직전.

## 몰아주기 전담 로직 (뼈대 원칙 · ③에서 상세화)

1. 입력 = **해당 뇌** 5세트의 번호 풀(+ confidence/reasoning 가능)
2. 출력 = **새 5세트** (기존 5와 구분 태그 `gather` 등)
