## 1. 원칙 (Cursor × 형)

| 대상 | 언어 | 비고 |
|------|------|------|
| **보고서·STATUS·형이 보는 UI 문구** | **한국어** | 초보 개발자도 이해 가능한 평어 |
| **코드·변수·JSON 필드명** | 영어 OK | 코드 블록 안만 |
| **코드 주석·라벨** | 한국어 OK | 오류 없으면 허용 |

- 영어 전문용어를 쓸 때는 **반드시 한국어 설명을 괄호로** 붙인다.  
  예: `ge3(3개 이상 적중률)` · `repack(몰아주기)` · `p(유의확률)`
- 표·섹션 제목·판정 문장은 **한국어 우선**. JSON 키는 근거(§6) 코드 블록에만.
- 채팅 「간략」≠ 문서 압축 — STATUS·보고서 본문은 근거·표 유지.

## 2. 필수 용어表 (보고서·STATUS 공통)
