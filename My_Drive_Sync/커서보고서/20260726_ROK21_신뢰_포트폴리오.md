# 20260726 — 신뢰 점검 + 다음에 한 일 (쉽게)

## 형 말씀
단순 랜덤이 아니라 **우리 패턴으로 뇌를 믿을 수 있어야** 한다 → **맞음.**  
아이디어는 계속 말하겠습니다. 선택지는 주지 않고 제가 정해서 갑니다.

## 코드로 확인한 사실
| 항목 | 결과 | 조치 |
|------|------|------|
| 홀짝(odd_even) 오탐 | 뇌 30% / 랜덤 39% → 자기강화 아님 | **수정 안 함** |
| 순위형 장선택 | 0.77 ≪ 보조 0.81 | **기각** |
| 뇌 15장 중 최고 | **2.22** | |
| 랜덤 15장 중 최고 | **2.28** | 뇌가 살짝 짐 (겹침) |
| 뇌 한 장 평균 | **0.80** ≈ 랜덤 한 장 | 평균은 비슷 |

→ 뇌가 “완전 가짜”는 아니지만, **비슷한 쪽으로 몰려** 최고 한 장 운이 랜덤보다 약함.  
그래서 **한 장만 고르기**보다 **서로 덜 겹치는 여러 장**이 맞음.

## 채택: 포트폴리오 3장
| 방식 | 평균 (3장 중 제일 잘 맞은 것) |
|------|-------------------------------|
| 보조채점 1장 | 0.80 |
| **우리 포트폴리오 3장** | **1.44** ← 채택 |
| 랜덤 3장 | 1.46 (거의 비슷) |

메타 기본 출력을 **분산 3장**으로 바꿈 (`meta_picker`).

## 지금 드는 아이디어 (제가 다음에 밀 것)
1. **예측 안에서도 겹침 줄이기** — 같은 뇌 5장이 너무  alike 하지 않게 (랜덤 함수 수정 없이 재선정/페널티)
2. 포트폴리오가 랜덤 3장을 **확실히** 이기게 다양성 가중 조정
3. 홀짝은 당장 손대지 않음 (오탐 루프 아님). `odd_even_balance`는 학습에만 쌓이고 예측에 거의 안 쓰임 → 나중에 연결하거나 정리
