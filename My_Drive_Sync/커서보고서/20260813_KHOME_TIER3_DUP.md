# K-HOME-TIER3-DUP — 홈페이지 「3등 2번」 확인

시각: 2026-08-13 · 형 「홈에서 백테 결과 확인, 3등 분명 2번」 · ge3미클레임 · 1237아님

## 1) 형이 본 것 = 맞다

홈 회차 히어로 「맞춘 결과: … 3등 **2**」는 **버그 집계가 아니다.**

집계 함수: `app/static/js/testlotto.js` `_testlottoHitSummarySourceRows`  
→ pool 10장 **+** 몰아주기(repack) 5장을 **행 단위로** 센다.  
같은 번호가 pool 한 장·몰아주기 한 장에 있으면 **3등 2**로 표시된다.

「목록 보기」에도 같은 번호가 두 줄로 나온다.

## 2) DB 실측 (발권 vs 원장)

| 경로 | 조건 | 결과 |
|------|------|------|
| `lotto_predictions` (발권 5장) | `matched_count>=5` | **0행** |
| `testlotto_pool_hit_ledger` | `hits>=5` | **2행** · 둘 다 **1210** |
| 대시보드 SQL rank3 (발권) | 뇌별 `matched_count=5` 보너스 없음 | stat/markov/review **전부 0** |

원장 2행 내용 (동일 번호):

- 1210 · markov · **pool** set3 · `[1, 7, 12, 17, 27, 38]` · hits=5 · bonus=0 · tier=3
- 1210 · markov · **repack** set3 · `[1, 7, 12, 17, 27, 38]` · hits=5 · bonus=0 · tier=3

당첨: `[1, 7, 9, 17, 27, 38]` 보너스 31 · 12≠9 → **3등 1조합**.

`hits=5 AND bonus_hit=0` 인 **다른 회차는 없음.**

## 3) 화면이 갈라지는 이유

| 화면 | 데이터 | 3등 |
|------|--------|-----|
| 회차 「맞춘 결과」 / 카드 | pool+repack | **2** (1210, 같은 번호) |
| 아코디언 「역대 전적」 / 대시보드 / 명예의 전당 | `lotto_predictions` 발권5 | **0** |

산 표(발권 5장) 기준으로는 3등 **0**.  
홈 풀화면 기준으로는 3등 **2행 = 고유 1장 복사**.

몰아주기 `signal_union` cap4가 pool 3등 세트를 통째 보존한 **설계**와 같다.

## 4) 하지 않은 것

- 홈 집계를 고유번호로 합치기(3등 1로 보이게) — **형 지시 없음 · 미패치**
- 3등 pool 세트를 발권 5장에 넣기 — **미패치**
- ge3/성적 클레임 없음
