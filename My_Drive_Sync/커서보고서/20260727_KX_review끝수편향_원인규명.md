## STEP 2. 코드 경로 (함수 단위)

```
predict_sets(draws, n_sets)                         # predict_review_king.py
├─ sorted_nums(draws[-1])                           # 직전 당첨 6수
├─ repeat_rate_after_draw(draws)                    # draw_features.py — 실제 draws만
├─ load_learn_state("review")                       # carry_over_boost 등
├─ weights[n] = rates[n]                            # ★끝수 비명시·번호 가중
│   ├─ prev_nums: × (1.8 * carry_boost)             # ★이월 증폭 (현재 carry_boost=0.2 → ×2.16)
│   └─ 비prev: × 0.85
├─ loop: random.choices(pool, weights=w, k=1) ×6    # 동결 라인 — 끝수 점수 없음
├─ pick = sorted(pick)                              # 정렬은 표시용, 선택 후
├─ tier1_filter(pick)                               # 합/홀짝/연대폭/연속 — 끝수 없음
└─ diversify_pick(results, n_sets)                  # confidence−Jaccard — 끝수 없음
```

## STEP 4. 판정·권고

### 4-1 원인 (기여도 순)

1. **1차 (주원인):** `repeat_rate_after_draw`의 번호별 비율이 끝수·연대에 비균등 투영  
   - 끝수별 평균 rate: **8=0.183 · 5=0.176 · 3=0.161 · 7=0.111**  
   - 예: 28→0.281, 15→0.222 vs 17→0.044, 37→0.035  
   - B 끝수비율 vs rate질량 L1=**0.104** ≪ vs 볼개수 L1=**0.193** → rate가 설명력 우위

2. **2차:** 직전 당첨 6수에 `×1.8×(1+carry_boost)` (현재 ≈×2.16) — 당첨 끝수를 단기 증폭. prev 끝수 hit는 대체로 균등(48–67)이라 1차보다 약함.

3. **배제:** 끝수 점수식·`ending_digit_boost` 적용·예측 폐루프·정렬 타이브레이크·끝수중복 허용도 이상.

### 4-2 교정안 (구현 금지 · ≤3)

| # | 안 | 예상 부작용 |
|---|----|-------------|
| 1 | rate를 끝수(또는 볼개수 prior)로 재가중/캡 | 이월·복습 시그널 약화 · mean 구조 변화 |
| 2 | 샘플 시 끝수 층화(과다 끝수 상한) | 세트 다양성·Jaccard 목표와 충돌 가능 |
| 3 | `ending_digit_boost`를 **감쇠**로 실제 배선(현재 미사용) | learn_state 의미 변경 · stat 경로와 비대칭 |

### 4-3 교정 불필요 논증 (확률 관점 · 병행 허용)

확률이 조합불변이므로, 끝수 편향이 있어도 **단일 조합의 1등 확률은 동일**(1/8,145,060).  
K-V dedup 후 k만 유효 레버.  
다만 WARRANT 관점에서는 「근거 없는 제3방향」이 **설명된 제1방향(rate 투영)** 으로 바뀌었고,  
자기강화 폭주는 기각되었다.  
→ **당첨확률 교정은 불필요**; 표시·감사 목적의 층화는 형 선택 사항.
