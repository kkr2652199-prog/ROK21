## 0) 한 줄 결론

**ROK21 테스트로또는 “정직한 walk-forward + 명분(warrant)” 쪽에서 웹 상용 앱보다 앞서 있지만, 심장부에 예측·복습 이중 파이프라인이 있어 UI·지표·학습이 서로 다른 숫자를 말할 수 있다.**  
K-UI-SSOT로 **표시 SSOT**는 맞췄고, 다음 최우선은 **엔진 SSOT 통합(K-PIPE)** 과 **walk-forward 품질 대시보드(K-WF-MON)** 이다.

## 2) ROK21 테스트로또 “심장” 실측

### 2-A. 아키텍처 (두 갈래)

```
[클릭 예측] engine → coordinator → AUX4 + referee + dedup → lotto_predictions
[복습 WF]  walkforward → predict_sets(raw) → brain_review → brain_page → detail UI
```

| 파일 | 역할 |
|------|------|
| `walkforward.py` `review_single_draw` | 복습 심장 — raw 3뇌×5세트 |
| `brains/coordinator.py` `run_coordinated_prediction` | 클릭 심장 — AUX 재랭킹 후 INSERT |
| `detail_service.py` `get_draw_detail` | 상세 SSOT (brain_page) |
| `learn_state.py` + `learn_state_cutoff.py` | 학습·심판 가중 (CUTOFF ON) |
| `routes.py` `/dashboard-summary`, `/brain/elite-tags` | **lotto_predictions** 집계 |

**K-UI-SSOT 이후 UI:** 과거 회차 표시 = brain_review ✓  
**아직 남음:** 「두뇌 예측」직후·대시보드·elite = lotto_predictions ✗

### 2-C. ROK21만의 강점 (벤치마킹하지 말고 **유지·확장**)

## 4) AI 협업 — “최선의 벤치마킹” 합의안

형·동생(Claude)·커서 3자 역할을 전제로, **과장 마케팅형 벤치(유튜브 Lotto Genius류)는 채택하지 않고**, **퀀트 WF + SAP XAI + ROK21 WARRANT**를 합친다.

### Layer 1 — SSOT 통합 (커서 실행 · 동생 설계)

**K-PIPE (P0)** — 심장 하나로

- **옵션 A (권장):** `review_single_draw` 마지막에 coordinator와 동일한 `_apply_aux_scoring` + dedup 적용 후 brain_review 저장  
- **옵션 B:** 클릭 예측도 brain_review/page에 mirror INSERT  
- **옵션 C:** 단일 테이블 `testlotto_prediction_runs` (run_id, phase=review|live, sets_json)

→ dashboard/elite/K-00 숙제가 **한 숫자**를 본다.

**K-METRICS-SSOT (P0)** — 집계 API를 brain_review 기준으로 전환 또는 dual-label (`source: review|live`)

### Layer 2 — Walk-Forward 품질 모니터 (gato + IBKR)

**K-WF-MON (P1)**

- 구간 API 확장: 뇌별 **fold별 avg_match σ**, 추세(up/down/flat — 이미 `tldRangeDiagnosis` partial)
- **랜덤 baseline** 대비: 6/45 무작위 기대 적중 ~0.8/6 수준과 비교 (BOOT 물리 상수 0.80 활용)
- UI: 상세页 「구간」탭 또는 메인 warrant 아래 **“복습 품질”** 카드

### Layer 3 — XAI 3단 (SAP Fiori)

**K-XAI-L3 (P1)** — 이미 70% 구현됨, 정리만

| 단계 | ROK21 현재 | 보강 |
|------|-----------|------|
| L1 Indicator | warrant 탭 배지 | dataSource 배지 (`복습`/`stage1`) |
| L2 Popover | policy strip | aux 4뇌 점수 미니 바 |
| L3 Page | testlotto-detail | SET_DIST 경고 배너 노출 |

### Layer 4 — 운영·협업 (LotteryAI flight recorder)

**K-RUN-LOG (P2)**

- `POST /predict/{n}` · WF batch마다 `{run_id, as_of, config_hash, brains, ms}` JSONL
- 1235 `_kawait_1235_loop.py --execute` 결과와 연결

### Layer 5 — 캐시·학습 정합

**K-CUTOFF-CACHE (P0.5)**

- `walkforward.run_review_loop` 종료 시 `clear_history_cache()`  
- `get_brain_learning_summary(brain_tag, as_of=draw_no)` API 확장
