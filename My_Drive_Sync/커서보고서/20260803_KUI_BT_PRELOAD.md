## 버그

1. 브라우저가 옛 JS(`20260730h`) 캐시 → 즉시반응 패치 미적용처럼 보임

## 패치

| 항목 | 내용 |
|------|------|
| `GET /backtest/draw-index` | 200회 요약 1회 프리로드 (~119ms) |
| JS `20260803b` | 탭 진입 시 인덱스→mem · 회차 전환 네트워크 0 |
| init | 재진입해도 현재 회차 즉시 `ShowDrawContext` |
| pool 캐시 있으면 | 백테 표시 후 풀 UI로 무음 업그레이드 |
