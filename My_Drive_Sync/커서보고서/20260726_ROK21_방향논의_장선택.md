## 커서 판단 (형 질문에 답)

### Q. 뇌 튜닝 먼저? 지금 3뇌 번호로 조합이 맞아?
- **조합(15장 쓰고 다시 고르기) 방향은 맞음.**
- **대규모 뇌 튜닝보다, 지금은 “고르기”를 먼저** 하는 쪽을 권함.
- 이유: 15장 안에 이미 평균 2.2개 맞는 장이 있는데, 우리가 고르면 0.8개밖에 못 맞춤 → **재료 문제보다 선택 문제.**

### Q. 3뇌+4보조 튜닝 방향이 틀렸나?
- **틀리지 않음.**  
  3뇌=만들기, 4보조=채점/고르기 도움, 메타=최종 담기.
- 보조를 “또 다른 예측”처럼 키우면 역할이 섞임 → 그건 비권고.

### Q. ROK21 DB 초기화?
- **전체 초기화는 비권고.**  
  당첨·복습 숙제가 이미 쌓여 있고, 지우면 다시 쌓아야 함.
- draws·review 유지 / 학습 가속만 이상하면 그것만 리셋 / 실험은 **복사 DB**로.

## 이번 실험: 장선택 학습 (I-13)

과거 성적만으로 “이번 15장 중 어떤 장이 잘 맞을지” 배워 고름.  
(당첨 미리 보고 고르기 없음)

| 방식 | 평균 맞춘 개수 (n=1144) |
|------|-------------------------|
| 제일 잘 맞은 장(참고) | **2.22** |
| 보조채점으로 고른 장 | **0.81** |
| 보조 + 끝자리 1개 수정 | **0.82** |
| **학습으로 고른 장** | **0.80** ← 보조보다 못함 |
| 학습 고른 뒤 끝자리 수정 | 0.78 |

→ **학습 장선택 채택 안 함.** 단순 선형 학습으로는 보조시드를 못 이김.
