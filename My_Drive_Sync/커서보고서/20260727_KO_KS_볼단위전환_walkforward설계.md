## STEP 2. 볼 편향 검정 — 전체 풀 (K-Q)

데이터: `lotto_draws` 1–1234 · 본번6 / 본+보너스7.

### 2-1. 출현빈도 (요약)

| 기준 | 총 볼슬롯 | 번호당 기대 E |
|------|-----------|---------------|
| 본번6 | 7404 | **164.533** |
| 본+보너스7 | 8638 | **191.956** |

(번호별 전체표는 벤치 JSON 없이 보고서 잔차 표로 갈음 — 상위·하위는 아래.)

### 2-2. 카이제곱 적합도 (df=44)

| 기준 | χ² | p | 판정 |
|------|-----|---|------|
| 본번6 | **28.59** | **0.965** | H0(균등) **기각 못함** |
| 본+보너스7 | **33.41** | **0.877** | 동일 |

**잔차(본번6) 상위5:** 34(+1.52), 27, 12, 13, 18  
**하위5:** 9(−2.22), 32, 22, 23, 41  

### 2-3. 번호별 이항 + Bonferroni페로니 / BH-FDR

- 모형: 회차당 P(출현)≈6/45, n=1234 (근사; 회차 내 비복원 의존 무시)
- α=0.05, 본페로니 α'=0.05/45≈0.00111
- **본페로니 유의: 0개**
- **BH-FDR 유의: 0개**
- 최소 p: 번호9 (count=136) p≈0.0165 → 보정 후 비유의

### 2-4. ★ 검정력 — 검출 가능 최소 편향폭

조건: 양측, 보정 α'=0.00111, 목표 power≈0.80, n=1234.

| 방향 | 최소 RR | 상대편향 | null 기대횟수 | alt 기대 |
|------|---------|----------|---------------|----------|
| 과다 | **1.298** | **+약 30%** | 164.5 | ≈213.5 |
| 과소 | **0.702** | **−약 30%** | 164.5 | ≈115.5 |

**명시:** 현행 n에서 우리는 **대략 ±30% 이상의 상대위험도(번호 출현확률 편향)** 만 신뢰 있게 볼 수 있다.  
그 이하(수 %대) 편향은 **현 표본으로 검출 불가**.

## STEP 3. 볼세트 층화 (K-R)

### 3-1. 식별자

앱·DB 전수: **볼세트/추첨기 식별자 없음** → 층화 **불가**(데이터 부재).

### 3-2. 검정력 시뮬 (세트당 n≈249 가정, 5등분)

| 풀 | n | 검출 가능 RR(과다) |
|----|---|-------------------|
| 전체 | 1234 | **+29.8%** |
| 층화 1세트 | 249 | **+66.3%** |

**손익:** 희석 제거 이득은 볼세트 효과가 클 때만 성립.  
현 시뮬만으로 보면 **n 감소 손해(30%→66%)가 지배적** → 층화가 자동으로 이득이라고 말할 수 없음.

### 3-3. 판정

**K-R = OPEN · 데이터 확보 대기**  
(방송 아카이브 자동수집은 이번 턴 금지 · 타당성만: 확보 시 세트별 편향이 ±60%급인지 먼저 탐색 가치가 있음. 소편향이면 전체풀이 유리.)

## STEP 4. walk-forward 뼈대 설계 (K-S) — 구현 금지

형 요구: t까지 관측 → t+1 예측 → 결과 → 학습 → 전진.

### 4-1. 미래참조 차단 지점

| 경로 | 상태 | 비고 |
|------|------|------|
| `_get_draws_before(target)` | **안전** | `draw_no < target` |
| `load_learn_state` 전역 (CUTOFF OFF) | **누수** | 미래 회차 `apply_feedback`이 이미 반영된 전역 행 |
| `get_referee_weights` | **누수** | 위와 동일 소스 |
| `ROK21_LEARN_CUTOFF=1` + `set_learn_as_of` | **완화** | draw_no < N 재구성 (K-09) |
| `get_feedback_summary(last_n)` | **누수 가능** | `ORDER BY draw_no DESC LIMIT` — **max_draw 없음** (`feedback.py:152`) |
| `get_brain_tag_ranking(..., max_draw_no=)` | 조건부 안전 | 호출자가 max 넘기면 OK |
| `lotto_predictions` 캐시 | 주의 | 당첨 후 matched 갱신된 행 재사용 시 평가 오염 |

설계 규칙: WF의 모든 학습 로드는 **`as_of=t` 컷오프 의무**. 전역 learn_state·DESC LIMIT 피드백 **금지**.

### 4-2. 재현성 (K-E/K-A 연계)

| 항목 | 설계 |
|------|------|
| seed | `seed = f(target_draw_no, brain_tag, protocol_version)` → `random.Random(seed)` |
| 동결 | 기존 `random.choices` **라인 문구 유지**하되, 모듈 RNG를 seed된 Random으로 교체하는 방식은 **형 승인 후** |
| 보장 | 동일 (draws_before, seed, protocol) → 바이트 동일 세트 |
| 캐시 | WF는 DB 캐시 hit 경로 **우회**(항상 재생성) 또는 캐시키에 seed 포함 |

### 4-3. ★ null 동시내장 (필수)

모든 WF 실행 출력:

| 열 | 내용 |
|----|------|
| model | 실측 뇌 |
| null | **동일 창·동일 세트수** 균일무작위 뇌 |
| 지표 | 아래 4-5 (mean/best만 단독 출력 **금지**) |

null 없는 성적표 = **출력 금지**(프로토콜 위반).

### 4-4. 과적합 방어

| 규칙 | 내용 |
|------|------|
| 기록 | 시험 파라미터 조합 수 **K** 를 벤치 메타에 필수 기록 |
| 보정 | K>1 이면 p/성능에 **다중검정 보정** (Bonferroni 또는 BH; PBO/Deflated Sharpe 개념 차용) |
| 금지 | K 미기록 리더보드 · 사후 선택 최고치만 보고 |

### 4-5. 평가지표 재정의안 (채택=형 승인)

| 지표 | 제안 |
|------|------|
| set mean / best | **폐기 또는 null-check 전용** (K-O/K-P/K-N) |
| 번호 로그우도 | 회차 t에서 예측 분포 p_i 와 당첨 6개 ℓ=Σ log p_{hit} |
| Calibration | 예측확률 분위 vs 실제 빈도 |
| Brier | 번호별 출현 확률 점수 |
| 볼빈도 적합 | χ² / 잔차 (층화 시 세트별) |

표본: 볼단위(수천)가 세트 적중(소수)보다 신호에 유리.
