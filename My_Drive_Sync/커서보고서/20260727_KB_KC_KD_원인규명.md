## PART 2. K-C — referee 가중 역행

### avg 출처

```
get_referee_weights (learn_state.py:108)
  → get_all_learn_states()
  → load_learn_state(tag)  # 기본: 전역 testlotto_brain_learn_state
  → recent_avg_match
식: w = (1 + avg×0.15) / Σw
```

| 항목 | 실측 |
|------|------|
| 테이블 | `testlotto_brain_learn_state.state_json` |
| 창(window) | **없음** — `apply_feedback`의 **누적 러닝 평균** |
| 갱신식 | `new_avg = (prev_avg*(rc-1) + matched_count) / rc` (`learn_state.py:157-159`) |
| `matched_count` 입력 | walkforward의 **best 세트** 적중 (`walkforward.py:91,110`) |
| review_count | stat **1272** / markov 1268 / review 1271 (≈전 회차 누적) |

### 1.687 / 1.606 / 1.661 의미

| tag | recent_avg_match | 의미 |
|-----|------------------|------|
| stat | **1.687** | 누적 ~1272회 **best** 적중 러닝평균 |
| markov | **1.606** | 동상 |
| review | **1.661** | 동상 |

최근100 **best** mean(1.64/1.62/1.74)과 비슷한 스케일.  
최근100 **set mean**(0.760/0.802/0.852)과는 **다른 지표**.

### 왜 7번 mean과 순서가 다른가

| 지표 | 순위 |
|------|------|
| set mean 100 | review(0.852) > markov(0.802) > **stat(0.760)** |
| best/러닝 avg | **stat(1.687)** > review(1.661) > markov(1.606) |
| referee_w | **stat(0.3348)** > review(0.3337) > markov(0.3315) |

**판정:** 가중치 산식은 `recent_avg_match`(best 누적)를 **정직히 반영**한다.  
“set mean 최저인 stat이 최고가중”은 **버그가 아니라 지표 불일치**(K-08 mean vs 학습용 best).  
실제 성적(set mean)을 반영한다고 **볼 수 없음**.
