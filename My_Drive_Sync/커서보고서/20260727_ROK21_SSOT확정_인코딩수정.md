## 1. 커밋 한글 깨짐 — 원인·조치

### (1) 원인 실측

| 항목 | 실측 |
|------|------|
| `i18n.commitencoding` | **utf-8** (이미 설정됨) |
| `i18n.logoutputencoding` | **utf-8** (이미 설정됨) |
| `core.quotepath` | **false** (이미 설정됨) |
| `chcp` | **949** (CP949 · 콘솔 기본) |
| PowerShell `OutputEncoding` | us-ascii / 콘솔 ks_c_5601-1987 |

**판정:** git i18n 설정 부재가 아니라, **커밋 메시지 주입 경로**가 문제였음.  
이전 턴에서 PowerShell `Set-Content -Encoding ascii` / 잘못된 파이프·콘솔 CP949로 한글이 `???`/`??`로 들어간 커밋이 존재 (`9aa4528` 등).  
히스토리 rewrite는 하지 않음.

### (2) 적용 (로컬 재확인)

```
git config --local i18n.commitEncoding utf-8
git config --local i18n.logOutputEncoding utf-8
git config --local core.quotepath false
```

재실측: 세 항목 모두 위와 동일.

### (3) 검증 방법 (본 턴 커밋)

- 메시지 파일을 **Python `encoding='utf-8'` (BOM 없음)** 으로 작성 후 `git commit -F`
- `git log --oneline -1` 에서 한글 정상 출력 확인
- 과거 깨진 커밋은 **그대로 둠**
