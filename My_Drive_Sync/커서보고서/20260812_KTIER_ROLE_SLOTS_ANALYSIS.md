## 1) 우리 앱·등수 정의 (실측 코드)

## 2) 문헌·벤치 대조

| 출처 | 요지 | 우리 채택 |
|------|------|-----------|
| Thaler&Ziemba / Ziemba ARFE | P(win) 불변 · 스킬은 **몫EV** | 등수P↑ 클레임 **기각** |
| Lottery wheeling / covering design | **조건부 보장**(예: 4개 맞으면 3개 티켓 보장) · 잭팟 보장 불가 | **포트폴리오 커버** 언어만 채택 |
| Cushing–Stewart 계열 코멘트 | 저등수 빈도↑는 있을 수 있으나 **기댓값=랜덤과 동일** 가능 | 성적게이트로 쓰지 말 것 |
| Mandel covering | 대규모 블록·자본 전제 | 10장 규모 **buy-the-pot/전수커버 PASS** |
| SSRN MIP pairwise similarity | 다장 티켓 **겹침↓**로 부분매치 기회 | L10 cover와 정합 · 배울 점 |
| K-P (FINDINGS) | 5적중 학습신호 부재 · 상위등수 축 폐기 후보 | **직접 3·2·1등 최적화 게이트 PASS** |

**벤치마크할 수 있는 것(앱 구조에 맞게):**
- 역할슬롯 도입 후 prefer/prize **비악화**
- 발권·pool 경로 **모니터** 병기
- 세트 간 Jaccard/커버(부분매치 분산)
- 원장(L2~L4)과 역할슬롯의 **정합**(어느 역할이 과거 몇 등수에 기여했는지 사후 기록)

**벤치마크하면 안 되는 것:**
- “3등 전용 슬롯 ge3↑ / 2등↑ / 1등↑” 단독 성적클레임

## 3) 채택 / PASS / 재해석

### PASS (그대로 구현 금지)
1. **「이 세트는 3등이 더 잘 된다」= P(3등)↑ 주장** — 문헌·K-P와 충돌.
2. **진짜 2등 전용(보너스 맞춤)** — 예측 시점에 보너스 미지. 보너스를 맞추려면 컨닝 또는 추측. **하드 2등 최적화 PASS**.
3. **10장으로 1등 covering 보장** — 수학적으로 불가에 가깝고 자본형 전략. PASS.
4. **지금 당장 expand_pool/repack 코드 APPLY** — 스펙·게이트 전 wire 금지(실수 방지).

### 채택 (앱 구조로 리팩터한 의미)
형 의도를 **역할 슬롯(portfolio roles)** 으로 번역한다. 이름은 등수를 **목표 라벨**로 두되, 성공정의는 prefer/prize·커버·원장이지 등수P가 아니다.

| 슬롯 | 장수 | 역할 ID | 엔진 의미 (우리 구조) |
|------|------|---------|----------------------|
| 뇌 10 중 1~5 | 5 | `skill_native` | **현행 그대로** pass0 `predict_sets` (뇌 스킬 본류) |
| 뇌 10 중 6~8 | 3 | `cover_r3` | **3등 지향 포트폴리오**: 본번호 5개 구조(고집중·부분커버). 보너스 무시 설계. covering/겹침↓ 힌트. P(3등)↑ 비주장 |
| 뇌 10 중 9~10 | 2 | `shape_r2` | **2등 지향 형태만**: 5맞+보너스 **가능성 공간** = 5핵심+가변1 · 보너스 직접예측 **안 함**. “보너스 맞춤” PASS |
| 몰아주기 1~5 | 5 | `focus_r1` | **1등 지향 압축**: 원장+신호로 번호 집중 조립(현 repack 강화). 몫EV는 review hint 유지 |

### 왜 이 번역이 안전한가
- 타깃 회차 정답 미사용 유지.
- 기존 pass0=스킬 / pass1=역할변형 으로 **자연 매핑**(지금 pass1은 중복호출뿐).
- 2등은 **보너스 미지**를 문서에 박아 과장 차단.
- 몰아주기=1등 지향은 형이 원래 말한 「상위 압축」과 동형.

## 4) 구현 전 필수 순서 (실수 방지)

```text
L1 smoke(베이스) 
 → L2 원장 SPEC (1~6·보너스·분산) 
 → L2b 역할슬롯 SPEC (본 분석 확정)
 → L3 원장 WIRE 
 → L5 뇌10 스킬감사 
 → L4 몰아주기←원장 
 → L4b/L5b 역할슬롯 WIRE(게이트) 
 → 안정 후 강제BT
```

역할슬롯 wire 전에 원장·스모크가 선행되어야, “등수↑” 착시로 APPLY하는 실수를 막는다.
