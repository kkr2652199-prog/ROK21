**날짜별 · 목적별**로 쌓아 두는 저장소다.

## 규칙
1. 폴더명: `YYYYMMDD_<짧은목적>/`
2. 각 폴더에 `README.md` (왜 찾았는지 · 결론 3줄 · 우리 앱과의 관계)
3. 원문 복붙 남발 금지. **요약 + URL + 우리 해석** 중심
4. **복사 금지 = 맹목적 모방 금지.** 벤치는 명분·언어·렌즈를 배우기 위함
5. 정답(1등 보장) 주장 금지. 독립 추첨 전제 유지
