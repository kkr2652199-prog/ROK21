# 철학 맵 — 외부 카리스마 vs ROK21 테스트로또

## 외부에서 자주 쓰는 “카리스마 언어”

| 렌즈 | 한 줄 철학 | 함정 | ROK21 대응 |
|------|------------|------|------------|
| 핫넘버 | 최근 자주 나온 흐름을 탄다 | 단기 덩어리≠미래 확률 | stat 감쇠빈도·핫 보너스 |
| 콜드/미출 | 안 나온 놈이 온다 | 도박사 오류 | overdue boost (상한 클램프) · gap 보조(미배선 파일 있음) |

| 홀짝·고저·합계 | 이상한 조합을 걸러낸다 | 필터가 당첨을 버릴 수도 | balance_aux · atlas 합계분포 |

| 테스트모드 | 과거 시점으로 검증 | 귀찮아서 안 함 | **우리 핵심** walkforward review |

## ROK21 테스트로또 카리스마 (우리 명분)

**이름(가칭): “정직 복습형 3+4”**

1. **과거만 보고 과거를 맞혀 본다** — `_get_draws_before(target)` (컨닝 금지)
2. **세 개의 서로 다른 렌즈** — 통계요정(빈도·끝수·이월) / 흐름술사(전이·쌍) / 복습왕(오답 반복)
3. **네 보조가 채점** — 오답·패턴·균형·심판 (생성과 채점 분리)
4. **틀린 이유를 문장으로 남긴다** — `missed_patterns` → learn_state
5. **1~1234 당첨표는 빅데이터, 예측표는 숙제장** — 정답 확정이 아니라 **명분 축적**

외부와 똑같이 하지 않는 이유:  
그들의 카리스마는 “이번 주 필출” 판매 언어에 가깝고, 우리는 **실험·복습·기록**이 카리스마다.
