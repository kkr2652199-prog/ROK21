# 외부 방법론 핀 (명분만 · 복제 금지)

> 인터넷 검색 흡수분. **필출 카피·코드 복제 없음.** 철학맵과 함께 읽기.

## 채택
| 방법 | 우리 대응 |
|------|-----------|
| Walk-forward / no lookahead | `_get_draws_before` · 메타도 target 이전만 |
| Ensemble · 다렌즈 투표 후 재조립 | 3예측 + Vote/하이브리드 메타 |
| 구조 서술 (홀짝·고저·합·연번·갭) | balance/pattern aux · 유사렌즈 swarm |
| 구조 피처 목록(SELMA 계열 아이디어) | L_struct/ending/gap/zone/pair — 아이디어만 |

## 거절
- “이번 주 필출/필배” 판매 언어
- 미래 peek 백테스트
- LSTM 메인 승격 (철학맵 보류 유지)

## 참고 링크 (방법론 명분)
- Walk-forward 시계열 검증 (일반 ML 문헌)
- EuroLotto V4 methodology — WF·앙상블 서술 (주장 복제 금지)
- DrawAnalytics / LottoLogic — 홀짝·합은 **조합적 서술**, 미래 확정 아님
- SELMA (6aus49) — 구조 피처 목록 참고용
