# 판단 메모 — 뇌 튜닝 vs 조합(메타) vs DB 초기화 (ROK21)

> 정답 없음. 커서 권고. 형 말과 달라도 근거로 말함.

## 1) 형 방향이 틀렸나?
**틀리지 않았습니다.**  
「3뇌가 뽑은 번호를 써서 조합한다」= 지금 PIN과 같음. 맞음.

다만 순서를 이렇게 나누는 게 좋습니다.

| 역할 | 하는 일 | 비유 |
|------|---------|------|
| 3 예측뇌 | 15장(또는 N×5) **만들기** | 재료 준비 |
| 4 보조뇌 | 만든 장을 **채점·고르기 도움** | 맛보기 |
| 메타/장선택 | 15장 안·합쳐서 **최종 1~K장** | 접시에 담기 |

→ **예측을 먼저 만들고 → 고른다** 구조는 유지하세요.  
「튜닝 다 끝난 뒤에만 조합」은 필수는 아닙니다.

## 2) 지금 뭐를 먼저?
**커서 권고: 장선택(고르기)을 먼저 깊게, 뇌 대규모 튜닝은 나중.**

이유(숫자):
- 15장 중 **이미 제일 잘 맞은 장** 평균 ≈ **2.2개**
- 우리가 고른 장 ≈ **0.8개**
- 차이 ≈ **1.4개** → “재료가 없어서”가 아니라 **고르기를 못함**

뇌 튜닝은 재료(2.2)를 2.4로 올리는 일.  
장선택은 0.8을 2.2에 가깝게 가져가는 일.  
지금은 후자 쪽이 구멍이 더 큽니다.

예외로 **짧게** 할 튜닝:
- 이미 한 `ending_digit` 수정 유지
- `odd_even` 같은 **명백한 오탐**만 짧은 점검
- 전구간 예측 다시 돌리기(대재학습)는 **장선택이 조금 이긴 뒤**

## 3) 3뇌·4보조를 어떻게 튜닝?
형 방향(예측 만들고 조합) **맞음**. 이렇게만 정리하면 됩니다.

- **3예측**: 서로 **다르게** 뽑게 (겹치면 풀이 가난해짐)
- **4보조**: 새 번호를 만들기보다, **고를 때 점수**로 쓰기 (지금 시드가 그 역할)
- 보조를 “또 다른 예측뇌”처럼 키우면 역할이 섞임 → 비권고

## 4) ROK21 DB 초기화 할까?
**전체 초기화는 비권고.**

사실:
- 복사본 + 지금 DB로 과거 숙제(복습표 약 1233회차)를 보고 있음 → 맞음
- `lotto_draws` 1234 · `brain_review` 풍부 · `lotto_predictions`는 상대적으로 적음

초기화하면:
- 지금까지 벤치·명분 숫자가 **다시 쌓여야** 함
- 원본 kweon은 안 건드림(이미 규칙) — ROK21만 비우는 건 가능하지만 **이득 < 손실**

권고:
- **당첨 표(draws)는 유지**
- **복습(review) 유지** (숙제장)
- 학습 가속치만 이상하면 **learn 상태만** 리셋 (이미 ending 때 일부 함)
- “깨끗이 처음부터”가 필요하면 → **새 실험용 DB 파일**을 복사해 쓰기 (본 DB 삭제 금지)
