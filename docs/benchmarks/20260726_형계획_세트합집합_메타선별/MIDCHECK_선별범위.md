# 중간 점검 — 어디서 고르나 · 뇌/세트 확장 시점 (분석)

> 패치 준비 단계. 추가 뇌·세트 수 변경은 **결론 난 뒤**. 지금은 구조·실측만.

## 1) 지금 구조 (코드 사실)

```
통계요정 5장 ─┐
흐름술사 5장 ─┼─→ 합쳐서 약 15장 풀 ─→ 보조4뇌가 채점 ─→ 메타가 고름(지금: 분산 3장)
복습왕   5장 ─┘
```

| 질문 | 답 |
|------|-----|
| 1뇌 5장 안에서만 고르나? | **아니요 (메타 기준).** |
| 1~3뇌 모든 장에서 고르나? | **예.** 풀 = 3×5 ≈ 15장. |
| 4보조는? | 새 장을 **안 만듦.** 만든 장을 **점수 매김** (고르기 도움). |

근거: `coordinator.py`가 3뇌 세트를 `candidates`로 합친 뒤 `_apply_aux_scoring`.  
`meta_picker.meta_assemble_sets`도 `pool_sets` 전체에서 포트폴리오 선택.

UI에 “뇌별 5장”이 보이는 것과, **메타가 최종으로 고르는 범위**는 다름.  
메타 = **전 뇌 합집합 풀**.

## 2) 실측으로 본 “한 뇌 vs 세 뇌”

(ROK21 testlotto, n=1233, 방금 집계)

| 범위 | 최고 장 평균 적중 | 고유 번호 평균 |
|------|-------------------|----------------|
| **3뇌 15장** | **2.22** | **36.5** |
| 통계요정 5장만 | 1.71 | 22.2 |
| 흐름술사 5장만 | 1.62 | 18.5 |
| 복습왕 5장만 | 1.69 | 20.6 |

- 답이 15장 안에 6개 다 들어옴 ≈ **28%** (한 뇌 5장만이면 &lt;1%대)
- 15장 최고가 통계요정 5장 최고보다 **엄격히 더 좋은 회차** ≈ 518/1233

→ **메타는 3뇌 전체에서 선별하는 것이 맞고, 한 뇌만 보는 것보다 유리.**

## 3) 추가 뇌? 세트 수 늘? (조언 · 지금 하지 말 것)

정답은 없음. 커서 방향:

| 선택 | 지금 시점 |
|------|-----------|
| 뇌 추가 | **아직 아님.** 다양성 게이트는 통과 수준이나, 뇌 best가 랜덤 15장 best보다 약간 낮음 = **겹침·농축 문제**가 먼저. 새 뇌는 “다른 렌즈”일 때만 의미 있음. |
| 5→더 많은 세트 | **아직 아님.** 장수만 늘리면 랜덤과  alike 한 장이 늘 → 비용↑, 고르기만 더 어려움. |
| 지금 할 일 | **분석·패치 준비:** (1) 15장 안 겹침 줄이기 (2) 분산 3장 출력 다듬기 (3) 고르기 규칙을 과거로만 검증 |

순서 (형과 동일):
1. **분석** (지금)  
2. **결론** (숫자로 채택/기각)  
3. 그다음 **튜닝 / 추가 뇌 / 세트 확장**

## 4) 한 줄 결론
- 선별 범위 = **1~3뇌 모든 예측 장(약 15장)** (+번호 재조립 실험은 별도, 지금은 장 단위 포트폴리오가 기본).  
- 추가 뇌·세트 확장은 **보류.** 먼저 겹침·고르기로 “지금 15장”을 믿을 수 있게 만들기.
