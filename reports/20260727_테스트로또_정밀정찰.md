## 3. 융합

클릭 경로의 “융합” = **보조4뇌 가중합 재점수** (`coordinator._apply_aux_scoring`).

| 항목 | 실측 |
|------|------|
| AUX 가중 | **하드코딩** `[0.25,0.25,0.25,0.25]` (`coordinator.py:29`) · 합=1 |
| 심판 가중 | **학습** `get_referee_weights`: `(1+avg×0.15)/Σ` → **합=1 보장** |
| DB `testlotto_brain_weights` | feedback이 갱신 · AUX 식에는 **직접 미사용** |
| 정규화 | 번호 weights(stat): boost 후 `Σ`로 재정규화. confidence: 0~99.5 클램프 |
| 확률 스케일 | 번호: 합≈1. confidence: 비확률(점수) |

### 현재값 실측

| tag | referee_w (live) | DB current_weight | recent_avg_match |
|-----|------------------|-------------------|------------------|
| stat | **0.3348** | 1.1687 | 1.687 |
| markov | **0.3315** | 1.1606 | 1.606 |
| review | **0.3337** | 1.1661 | 1.661 |

식: `final_conf = min(99.5, base×0.5×brain_w + aux_score×40 + base×0.1)`

| 상황 | 동작 |

## 5. 학습 루프

### learn_state.py

| 항목 | 내용 |
|------|------|
| 학습 대상 | `adjustments`(boosts) · `miss_counts` · `recent_avg_match` · `review_count` |
| 저장 | `testlotto_brain_learn_state.state_json` (+ `testlotto_brain_weights` 갱신) |
| 소비 | `load_learn_state` ← stat/review 예측 · `get_referee_weights` ← AUX 재점수 · `predict_statistical` boost 배선 |

### boost 계산식 (인용)

`apply_feedback` (`learn_state.py:134-150`):
```
miss_counts[pattern] += 1
if count >= 3:
  adj[boost_key] = min(cap, cur + 0.05)
caps: carry 0.2 / ending 0.3 / overdue 0.2
```

stat 소비 (`predict_statistical.py:187-215`):
```
weights[n] *= 1 + overdue_b   # gap≥30
weights[n] *= 1 + ending_b    # 직전 끝수 & miss ending>0
weights[n] *= 1 + carry_b     # 직전 번호
→ Σ 재정규화
```

### 피드백 → 다음 예측

```
당첨 존재 → review/walkforward → apply_feedback(전역 쓰기)
  → 다음 predict: load_learn_state → weights/conf
  → get_referee_weights → AUX confidence
```

끊긴/약한 지점:
- **markov** `predict_sets`는 learn_state **미사용** (boost 미적용)
- `ending_digit_boost` 현재 **0.0** · miss ending=0 → ending 경로 휴면
- 클릭 단발 예측만으로는 `apply_feedback` **자동 호출 안 함**(백테/복습 경로)

### LEARN_CUTOFF

| | OFF (기본) | `ROK21_LEARN_CUTOFF=1` + `set_learn_as_of(N)` |
|--|------------|-----------------------------------------------|
| `load_learn_state` | 전역 DB 행 | `learn_state_cutoff`가 `draw_no < N` 피드백만 재구성 |
| `apply_feedback` | 전역 쓰기 | **동일**(전역만 갱신 · 컷오프 오염 방지) |
