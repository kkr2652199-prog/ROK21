### (6) 학습 루프

#### `learn_state.py`가 학습하는 것
- 테이블: `testlotto_brain_learn_state` (brain_tag별 `state_json`)
- `adjustments`: carry/ending/pair/consecutive/overdue/odd_even boost
- `miss_counts`: 오답 패턴 카운트
- `recent_avg_match`, `review_count`, `last_draw_no`
- 컷오프 읽기: `ROK21_LEARN_CUTOFF=1` 시 `learn_state_cutoff.try_load_cutoff` (쓰기·apply는 전역)

#### boost 계산식 (실제)
```
miss_counts[pattern] += 1
if count >= 3:
  adj[boost_key] = min(cap, cur + 0.05)
caps: carry 0.2 / ending 0.3 / overdue 0.2 / pair·consec·odd_even 0.5
```
stat 예측 반영 (`predict_statistical.py:177~219`):
```
weights[n] *= 1 + overdue_b   (gap≥30)
weights[n] *= 1 + ending_b    (직전 끝수, miss_counts.ending>0일 때)
weights[n] *= 1 + carry_b     (직전 번호)
→ 재정규화
```
