## 1. 무엇을 쟀나

**같은 파라미터·같은 추첨 결과**인데 seed 만 바꿨을 때 ge3 가 얼마나 흔들리는지를 쟀다.
이건 추첨이 랜덤이라 생기는 흔들림(이항 SE)과는 **다른 잡음**이다. 우리 파이프라인이
스스로 만들어내는 잡음이고, 튜닝 판정을 직접 오염시킨다.

이전 SEED-DIAG 는 n=100 한 점에서 seed 5개로만 쟀다(폭 0.14).
이번엔 전구간을 통째로 돌려 저장한 뒤, 창 크기를 바꿔가며 사후 재집계했다.

## 3. 잡음 곡선 — 창 크기에 따른 흔들림 (stat)

`seed 표준편차` = 같은 데이터에서 seed 만 바꿨을 때의 흔들림 (우리가 만든 잡음).
`이항 SE` = 추첨이 랜덤이라 어쩔 수 없는 흔들림.
`팽창계수` = 앞을 뒤로 나눈 값. 1 보다 크면 파이프라인이 잡음을 **더하고** 있다는 뜻.

## 4. 가장 중요한 발견 — 줄어들지 않는 바닥

위 표에서 창을 키워도 seed 표준편차가 **1/√n 만큼 줄지 않는다**. 이항 SE 는
n=50→1183 에서 4.86배 줄지만, seed 표준편차는 3.24배밖에 안 줄었다.

분산을 다음 형태로 적합했다 (타일 수 가중 최소제곱).

```
seed_var(n) = a²/n + b²
a = 0.25897      b = 0.010127      가중 R² = 0.998519
```

| 창 n | 관측 표준편차 | 적합값 |
|---|---|---|
| 50 | 0.038032 | 0.037998 |
| 100 | 0.027652 | 0.027807 |
| 200 | 0.020387 | 0.020926 |
| 400 | 0.01792 | 0.016438 |
| 800 | 0.015882 | 0.013652 |
| 1183 | 0.011754 | 0.012619 |

`a²/n` 은 회차를 늘리면 평균되어 사라진다. 문제는 **b = 0.010127** 다.
이건 회차를 무한히 늘려도 남는다. 즉 **백테스트를 아무리 길게 해도 seed 선택만으로
ge3 가 표준편차 0.010127 만큼 계속 흔들린다.**

### 이 바닥을 실제 판정에 대보면

전구간 walk-forward(K-FUTURE-WIRE-FULL, n=1182)가 측정한 null 대비 Δ 는 **+0.0047** 였다. 바닥 0.010127 **보다 작다**. 표본을 더 모아도 결론이 나지 않는 크기라는 뜻이다.

## 5. R38 게이트 보정

seed 잡음과 추첨 잡음은 원인이 다르므로 분산을 더한다. 팽창은 n 에 따라 달라진다
(작은 n 에서는 추첨 잡음이 지배하고, 큰 n 에서는 seed 바닥이 지배한다).

```
총 SE(n) = sqrt( p0(1−p0)/n  +  a²/n + b² )
```

## 7. 결론

전구간 n=1183 · seed 10개에서 stat 의 ge3 는 0.094675~0.130178 (폭 **0.035503** · 표준편차 0.011754) 로 갈린다. 파라미터도 데이터도 추첨 결과도 전부 같은데 seed 하나로 이만큼 움직인다.

더 중요한 건 잡음이 **1/√n 으로 줄지 않는다**는 점이다. 분산을 `a²/n + b²` 로 적합하면 b = **0.010127** 가 남는다(가중 R²=0.998519). 회차를 무한히 늘려도 seed 선택만으로 ge3 가 표준편차 0.010127 만큼 흔들린다는 뜻이다.

이 바닥을 실제 판정에 대보면: 전구간 walk-forward 가 측정한 null 대비 Δ 는 **+0.0047** 였다. 바닥 0.010127 **보다 작다**. 즉 그 판정은 표본을 더 모아도 결론이 나지 않는다.

실무 결론: n=50·10셀 판정의 보정 선택보정 임계는 **0.209643** 이다(보정 전 0.16). 이전 n=100 단일 추정(폭 0.14)은 이제 곡선과 바닥값으로 대체됐다.
