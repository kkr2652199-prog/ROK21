## 0) 외부 AI(젠스파크)용 — 압축 후 GitHub 확인 용어

형이 젠스파크에 **「깃허브 확인해줘」** 라고 할 때, 아래 큐를 쓰면 흐름이 이어진다.

### 추천 큐 (복붙)

```text
동생, ROK21 RESTORE.md 읽고 시작해.
SSOT=https://github.com/kkr2652199-prog/ROK21 main · 로컬 D:\ROK21 · 포트 7021.
원본 kweon(D:\3kweon · 264de3c) 동결·미접촉.
수치=docs/benchmarks/*.json · 결함=FINDINGS.md · 라벨=WARRANT.md 가 원본.
다음 1건=NEXT_ACTIONS.md 의 ## NEXT (1건) 만. 추정 금지·미확인이면 질문.
```

### 용어 사전 (압축 대비)

| 말 | 뜻 |
|----|-----|
| **SSOT** | 진실의 원본 저장소 = `kkr2652199-prog/ROK21` main |
| **RESTORE.md** | 동생(외부AI) 압축복원 **단일 파일**. 상단 「동생 복귀 5줄」 |
| **BOOT.md §1** | 커서 기준 「지금/직전/다음」 3줄 |
| **NEXT_ACTIONS** | **다음 할 일 정확히 1건** (`## NEXT (1건)`) |
| **FINDINGS / WARRANT** | 결함 ID 상태 / 뇌 명분 라벨 원본 |
| **benchmarks JSON** | 수치 원본. 채팅 기억·BOOT 숫자보다 우선 |
| **K-xx** | 결함/작업 ID (예: K-AD, K-06) |
| **동결토큰** | `random.choices` · `_get_draws_before` · boost 상한 — 수정 금지 |
| **가드훅 guard_boot** | Cursor가 매 프롬프트에 HEAD·지금·NEXT를 **자동 주입** (젠스파크에는 없음 → RESTORE 필수) |

※ 젠스파크에는 Cursor hooks가 **없음**. 따라서 외부AI는 반드시 **GitHub의 RESTORE.md**를 열어야 한다. 커서 쪽은 훅이 보조.

### 추가 보안 (젠스파크 측 · 선택)

1. 매 지시서 헤더에 `근거: RESTORE.md / NEXT_ACTIONS / FINDINGS` 고정  
2. 수치마다 `(출처: …json)` 병기 — 없으면 지시서에 쓰지 않음  
3. 압축 직후 첫 메시지 = 위 추천 큐만 (새 작업 지시 금지)
