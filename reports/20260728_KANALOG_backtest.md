## 1. 형이 제안한 방법 → 테스트 프로토콜

| 단계 | 내용 |
|------|------|
| base | **N-1** 회차 당첨 6개 (예: 1233→ `[2,7,20,25,37,40]`) |
| analog | 1..N-2 중 base와 유사 회차 TOP-15 (K-ANALOG norm_spec) |
| 관측 | 각 analog의 **실제 다음 추첨(analog+1)** 번호만 사용 |
| 예측 | analog+1 번호를 6가지 방식으로 집계 → **N** 예측 |
| 검증 | 예측 vs N 실제 당첨 · **walk-forward**(analog+1 < N, 컨닝 없음) |

1235 미발표이므로 **과거 735회(500~1234)** 를 동일 규칙으로 반복 테스트.

## 2. 테스트한 6+1 방법 (다른 AI 아이디어 포함)

| ID | 설명 | 출처 |
|----|------|------|
| **M_freq** | analog+1 번호 단순 빈도 TOP-6 | 기본 |
| **M_weighted** | 유사도 score 가중 빈도 | 기본 |
| **M_overlap3** | 겹침≥3 analog만 가중 | 기본 |
| **M_anchor_pair** | base 앵커와 analog+1 co-occur lift | AI(statlotto) |
| **M_positional** | 정렬 자리 일치 시 analog+1[j] 가중 | AI(archive) |
| **M_greedy_pair** | 1위 번호 → co-occur 탐욕 확장 | AI |
| **M_random** | 균등 무작위 6개 (회차별 seed) | baseline |

이론 기대값(독립): **6×6/45 ≈ 0.80** 개 일치/회차.

---

## 3. 핵심 결과 (735회)

| 방법 | 평균 일치 | 3개+ 비율 | 최대 일치 | vs random |
|------|-----------|-----------|-----------|-----------|
| **M_random** | **0.816** | 2.0% | 3 | — |
| M_positional | 0.803 | 2.0% | 3 | −0.014 |
| M_weighted | 0.784 | 1.8% | **4** | −0.033 |
| M_anchor_pair | 0.784 | 1.9% | 3 | −0.033 |
| M_overlap3 | 0.781 | 2.0% | 4 | −0.035 |
| M_greedy_pair | 0.762 | 2.2% | 3 | −0.054 |
| M_freq | 0.761 | 1.9% | 4 | −0.056 |

**결론:** 6가지 analog 집계 **모두** 무작위 baseline보다 평균 적중 **낮음**.  
M_weighted가 random을 이긴 회차 = **31.2%** (무승부 33.6%, 패 35.2%).

→ **「유사 과거 → 다음 관측 집계」로 6개를 뽑는 방식은 예측 엔진으로서 우위 없음** (735회 기준).

## 4. 1233 → 1234 케이스 (형 시나리오)

| 항목 | 값 |
|------|-----|
| base (1233) | 2, 7, 20, 25, 37, 40 |
| 실제 (1234) | 1, 15, 19, 31, 35, 43 |
| TOP1 analog | **214회** (겹침 4) — 793 아님 |
| 214→215 관측 | 2, 3, 7, 15, 43, 44 |
| 예측 (M_weighted) | 3, 5, 10, 11, 24, **43** → **1개** 일치 |
| M_greedy | …, **35**, … → **1개** (35는 실제에 있으나 6개 중 1개만) |

**793회** (겹침 3: 15,35,43)는 **1234 번호를 직접 base**로 PREP 검색할 때 1위였음.  
**1233→1234 예측** 경로에서는 TOP1이 214라 **형이 본 793→794 체인과 다른 경로**.

| PREP (1234 direct) | BT (1233→1234 predict) |
|--------------------|--------------------------|
| base = 1234 당첨 | base = 1233 당첨 |
| 1위 793 → 794 관측 6,7,18,19,30,38 | 1위 214 → 215 관측 2,3,7,15,43,44 |
| **설명·관측 체인** | **예측 실험** |

## 5. 발견된 패턴

### 5-1. 가끔 터지는 회차 (outlier)

- **696회:** M_freq/M_weighted **4/6** (1,7,16,18) — random 0/6  
- **1136회:** 3/6 수준 (JSON top5 참조)  
- 전체 735회 중 3개+ = 약 **1.8~2.2%** (random과 유사)

### 5-2. TOP1 겹침

- 500~1234 구간: **모든 회차** TOP1 analog 겹침 ≥ 3 (과거 500+회 적재)  
- 겹침≥3만으로는 **필터 효과 없음** — subset=전체 735

### 5-3. 방법 간 상관

- M_freq ≈ M_weighted ≈ M_overlap3 (1234 포함 다수 회차 동일 예측)  
- M_positional·M_greedy_pair는 분산 있으나 **평균은 여전히 random 미달**
